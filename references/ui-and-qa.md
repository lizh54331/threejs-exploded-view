# UI 规格与验收

> 四件套：构件清单、详情卡、参数表、操作引导。少一件就不算完成。

---

## 1. 布局（1920×1080 为基准）

```
┌──────────────────────────────────────────────────────────┐
│ 标题 + 英文副行                              状态角标     │
│ ┌────────────┐                            ┌────────────┐ │
│ │ 构件清单    │                            │ 详情卡      │ │
│ │ 288px       │         3D 画布           │ 316px      │ │
│ │ 左 24       │                            │ 右 24      │ │
│ │ 上 92       │                            └────────────┘ │
│ │            │                            ┌────────────┐ │
│ └────────────┘                            │ 参数表      │ │
│                                            └────────────┘ │
│              ┌──────────────────────────┐                │
│              │ 底部引导条（可收起）      │                │
│              └──────────────────────────┘                │
└──────────────────────────────────────────────────────────┘
```

- 面板：`rgba(9,15,21,0.74)` + `backdrop-filter: blur(16px)` + 1px 描边 `rgba(120,170,210,0.18)`，圆角 12；
- 强调色：青 `#35d6ff`（交互）+ 暖 `#e8b071`（参数胶囊），正文 `#a8bdd0`，标题 `#cfe4f5`；
- 数字与英文一律等宽字体（`ui-monospace, Consolas`），中文用系统黑体；
- 响应式：<1180px 隐藏参数表、详情卡移到底部；<860px 只留清单。

---

## 2. 构件清单（左）

每行：`编号` + `中文名 / 英文小字` + `参数胶囊`。

- 编号两位补零（`01`），青色 70% 透明；
- 选中态：底色 `rgba(53,214,255,0.13)` + 描边 42%；
- 整行可点（点击 = 选中 + 拆解 + 相机不强制移动）；
- 列表 `max-height: 48vh` + 自定义滚动条；9 个构件时刚好放得下。

---

## 3. 详情卡（右上）

```
分类 · ENGLISH          ← 9.5px 等宽，青色
名称                    ← 17px，600
说明 1–3 句             ← 12.5px / 1.78 行高，讲"是什么、为什么这样"
┌ 参数 ┬ 值 ┐          ← 3–6 行，键左灰、值右等宽
└──────┴────┘
```

未选中时的空态文案要告诉用户"可以点什么"，而不是留白。

---

## 4. 参数表（右下）

整机/场景固定参数 6–8 行：尺寸、重量/标高、关键规格、材料。**必须与详情卡的参数区分开**：这里是全局，详情卡是单件。

---

## 5. 引导条（底部）

`左键拖拽 旋转 · 滚轮 缩放 · 右键拖拽 平移 · 点击部件 拆解 + 详情 · 空格 拆解/重组 · R 复位`

- 胶囊形，半透明深底，`<b>` 强调按键；
- 右下角 × 收起（收起后不再自动出现）；
- 页脚不要放"版权 2024"这类无信息内容。

---

## 6. 3D 标签（投影）

```html
<div class="lbl">
  <span class="dot"></span>
  <span class="txt"><span class="t1">名称</span><span class="t2">参数</span></span>
</div>
```

- 定位：`position:absolute; transform:translate(-50%,-50%)`，`pointer-events:none`；
- 尺寸：内边距 4/8，主行 10.5px，副行 8.5px 等宽；
- 显示条件：`explode > 0.4` **且**投影 `z ∈ (-1, 1)`（背后隐藏）；
- 防重叠：每帧收集 → 按 `y` 排序 → 同列（`|Δx| < 180`）且与上一个间距 < 28px 时下推；
- 非选中件透明度降到 0.5，突出当前件。

## 7. 验收脚本（必须真跑）

### 7.1 截图

```bash
node tools/shot.mjs --out shots/a.jpg --w 1600 --h 1000
node tools/shot.mjs --out shots/b.jpg --w 1600 --h 1000 --pick <partKey>
node tools/shot.mjs --out shots/c.jpg --w 1600 --h 1000 --eval "const s=window.__scene; s.camera.position.set(...); s.controls.target.set(...); s.controls.update();"
```

看三件事：合体是否读得出主体、拆解是否每件都露出来、标签有没有叠。

### 7.2 真实点击（不能只调函数）

```js
// 把世界坐标投影成屏幕坐标，再 page.mouse.click(x, y)
const v = camera.position.clone().set(0, 1.0, 0).project(camera);
await page.mouse.click((v.x*0.5+0.5)*innerWidth, (-v.y*0.5+0.5)*innerHeight);
```

断言四件事：`#dName` 变化、`.part.on` 数量 = 1、`explode > 0.5`、`.lbl.show` 数量 = 构件数。

### 7.3 清单与重组

点清单第 N 项 → 标题变化且参数行 > 0；点 `#btnExplode` → `explode → 0` 且标签隐藏、按钮文案回到"拆解"。

### 7.4 硬指标清单

- [ ] 打开页面 0 个 page error / 0 个 404；
- [ ] 真实点击能选中、拆解、出标签；
- [ ] 重组后位置与初始完全一致（无累计漂移）；
- [ ] 1280×800 与 1920×1080 各看一次，面板不遮挡主体；
- [ ] 每个构件在拆解态都可见（无完全遮挡）；
- [ ] `README.md` 写了启动方式、构件表、取舍说明；
- [ ] 交付物包含 `启动预览.bat`（或等价的启动脚本）。
